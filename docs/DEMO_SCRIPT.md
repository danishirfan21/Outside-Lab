# 60–90 second real demonstration script

Use this only after the live Backboard request succeeds. Do not substitute a starter suggestion for an AI result.

1. **0:00–0:10 — What I Built:** Show the welcome screen. Say: “Outside Lab is designed to make the screen interaction short: check in, go outside, come back curious.”
2. **0:10–0:22 — Real check-in:** Select a real mood, activity, and short duration. Start the session and show the timestamp-driven timer.
3. **0:22–0:35 — Demo:** Put the phone down. Show real footage from the activity, ideally filmed separately. Do not imply that a short clip represents a completed multi-minute session.
4. **0:35–0:50 — Return:** Return after the actual elapsed time. Record an honest after-session rating and optional observation, then show the saved journal entry.
5. **0:50–1:10 — How I Built It:** Explain that the browser stores sessions locally, while the server sends only a bounded summary to Backboard when the AI button is pressed.
6. **1:10–1:25 — Open Innovation:** Show the actual Qwen/Backboard response. Explain that Qwen proposes the next comparison from recorded history; duration and mood-difference calculations remain ordinary deterministic code.
7. **1:25–1:30 — Limits:** Say: “This is self-reported, not GPS-verified or medical advice. One mood change does not prove a cause.”

## Recording safety checklist

- Use a safe, accessible outdoor place; do not reveal an address or precise location.
- Hide API keys, access codes, notifications, and private notes.
- Show an actual successful AI response only after the server is configured and working.
- Label future ideas as future ideas.
