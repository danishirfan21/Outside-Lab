OUTSIDE LAB — START HERE

Fastest preview (no npm installation):
1. Open preview/index.html in your web browser.
2. Complete a check-in, start a timer, end it, rate your mood, see your journal.
3. The AI button requires your own Backboard API key on a separate FastAPI server.

To enable real Backboard AI on Windows:
1. Open PowerShell in this extracted folder.
2. cd backend
3. py -m venv .venv
4. .\.venv\Scripts\Activate.ps1
5. pip install -r requirements.txt
6. copy .env.example .env
7. Edit backend/.env with your BACKBOARD_API_KEY (never publish this file).
8. python check_models.py (verify available Qwen model; adjust BACKBOARD_MODEL if needed).
9. uvicorn app.main:app --port 8000
10. Open another PowerShell: cd preview; py -m http.server 8787
11. Open http://localhost:8787 and try Ask open AI.

For React source: cd frontend; npm install; npm run dev. It uses the local backend.

Android on the same Wi-Fi: keep the backend on 127.0.0.1:8000, run `npm run dev`, use `Get-NetIPAddress -AddressFamily IPv4` to find this laptop's address, then open `http://<LAPTOP_IPV4>:5173` in Android Chrome. Allow Vite through Windows Firewall on Private networks only. The phone uses Vite's `/api` proxy; do not expose port 8000.
